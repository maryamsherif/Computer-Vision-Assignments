# Computer Vision Project

This repository contains two assignments focused on implementing computer vision algorithms from scratch using Python, OpenCV, and NumPy. The projects demonstrate fundamental and advanced image processing techniques, including filtering, edge detection, feature extraction, and analysis of Martian terrain images.

## Projects

### 1. **Basic Image Processing Functions (`allFunc.py`)**
This project implements core computer vision algorithms from scratch, including:
- Image filtering (Gaussian, median)
- Edge detection (Sobel, Canny)
- Histogram equalization
- Morphological operations (dilation, erosion)
- Feature detection (Harris corner detection)

**Skills Demonstrated:**
- Proficiency in Python, NumPy, and OpenCV
- Understanding of fundamental computer vision concepts
- Ability to implement algorithms from scratch

### 2. **Martian Terrain Image Analysis (`Mars_Assignment_2_Team_96.ipynb`)**
This project focuses on analyzing Martian terrain images using advanced computer vision techniques, including:
- Image preprocessing and filtering
- Feature extraction and edge detection
- Hough Transform for line and circle detection
- Contour analysis and template matching

**Skills Demonstrated:**
- Advanced image processing and analysis
- Problem-solving with real-world datasets
- Collaboration in a team environment

## Requirements
To run the code in this repository, you need the following Python libraries:
- `opencv-python`
- `numpy`
- `matplotlib`
- `jupyter` (for the Jupyter Notebook)

You can install the required libraries using:
```bash
pip install opencv-python numpy matplotlib jupyter
```

## Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/maryamsherif/Computer-Vision-Assignments.git
   cd Computer-Vision-Assignments
   ```
2. Run the Python script or Jupyter Notebook:
   - For `allFunc.py`:
     ```bash
     python assign1/allFunc.py
     ```
   - For `Mars_Assignment_2_Team_96.ipynb`:
     ```bash
     jupyter notebook assign2/Mars_Assignment_2_Team_96.ipynb
     ```
